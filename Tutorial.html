First Steps in the App

  • Create a project: Click the "New Project" button on the Project Board, fill in the details, and choose a status.
  • Create tasks: Within a project column, click "+ Add Task" to add tasks with a priority, assignees, and optional subtasks.
  • Assign tasks: Select team members from your manager hierarchy.
  • Collaborate: Add comments to tasks by clicking the comment icon on a task card. Use @username to mention teammates.
  • Customize: Adjust font size, toggle dark mode, and change notification preferences in Settings (accessed via your profile icon bottom-left).

Core Features

  • Meeting Agendas: Create dynamic agendas for recurring meetings. Add headers, text items, and seamlessly embed interactive task links directly into the agenda. Share agendas with specific team members via a sharing pop-up.
  • Supervisor Tools: If you are listed as a manager for other users, you can use the Supervisor Tools tab to view projects and tasks specifically assigned to your direct reports.
  • Notifications: The system sends emails for Task Assignments, Mentions, Task Completions, Due Date Reminders, Weekly Digests, and Agenda Shares.

Troubleshooting & Rules

  • Permissions Error ("Cannot assign task to this user"): You can only assign tasks to yourself or your direct subordinates (users who have you listed as their Manager in the system).
  • Tasks/Projects not appearing: The default Project Board only shows items assigned to YOU. If you assigned a task to someone else, you must view it from the Supervisor Tools tab.
  • Mention extraction not working: The @mention must match the exact display name handle or email prefix of an already onboarded user.
